# University AI Chatbot — Llama 3.2:1B + RAG

A complete local university knowledge-base chatbot using:

- React + Vite frontend
- Flask backend
- Ollama + Llama 3.2:1B
- ChromaDB
- Sentence Transformers embeddings
- PDF ingestion
- University website crawling
- Browser voice input
- Browser text-to-speech
- Source references
- Conversation history
